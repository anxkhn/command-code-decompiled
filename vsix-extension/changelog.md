# Changelog

All notable changes to the Command Code VS Code extension will be documented in this file.

## [0.0.1] - 2026-02-06

### Added
- Initial release of Command Code VS Code extension
- Real-time editor context sharing with Command Code CLI via IPC
- Active file, cursor position, and selection tracking
- Open files list shared with CLI
- Status bar indicator showing CLI connection state
- Unix socket-based IPC communication with session registry discovery
- Configurable context options via VS Code settings
